# OpenSCAD example

A parametric L-bracket for the OpenSCAD walkthrough:

| File | What it is |
| --- | --- |
| `bracket.scad` | Source — five Customizer parameters (`base_w`, `base_d`, `height`, `thickness`, `hole_d`), plain OpenSCAD, no libraries |

Copy `bracket.scad` into a scratch folder and follow along. Applying a
Customizer value writes `bracket.scad-params.json` beside *your copy* — the
published file stays at its defaults.
